# Patente Pro — контекст для быстрого старта

Тренажёр итальянского экзамена на права (patente B). Локальное приложение:
Node.js-бэкенд **без npm-зависимостей** + vanilla-JS фронтенд **без сборки**
в стиле Minimal Brutalism. Владелец: vlntddn (общение на русском).

## Команды
- `npm start` — запуск на http://127.0.0.1:3000 (установка не нужна, Node ≥ 18)
- `npm run app` — десктопный лончер: своё окно, прогресс в per-user каталоге
- `npm run dev` — с авторестартом
- `npm test` — тесты домена (node --test, должны быть зелёными перед пушем)
- `npm run fetch-images` — докачать картинки знаков (идемпотентный)

## Где что лежит
- Полная архитектура с диаграммами: **docs/ARCHITECTURE.html**
- Роадмап и текущий фокус: **docs/TODO.md** (сейчас — Фаза 1: дизайн/UX)
- История решений: **docs/DEVLOG.md** (новую запись — при каждой значимой работе)
- `server/progress.js` — вся доменная логика и валидация (единственное место мутаций)
- `public/js/views.js` — все экраны; `public/js/main.js` — hash-роутер
- `public/styles.css` — дизайн-токены в CSS-переменных (`--ink`, `--accent`…)
- `data/` — банк вопросов (read-only); `storage/` — прогресс пользователя (не в git)
- `bin/` — десктопный лончер; `install.sh` / `install.ps1` — установщики
  (macOS `.app`, Linux `.desktop`, Windows-ярлыки), прогресс вне папки приложения
- `legacy/` — старая скомпилированная версия, не трогать

## Правила проекта
1. Никаких npm-зависимостей и шага сборки до Фазы 3 (см. TODO.md).
2. Секреты/конфиг — только `.env` (есть `.env.example`); во фронтенде — никогда.
3. Мутации данных — только через сервер с валидацией (ValidationError → 422).
4. Пользовательский текст в DOM — текстовыми узлами через `el()`, не innerHTML.
5. Запись на диск — только через `JsonStore` (атомарность).
6. Новая серверная логика — с тестом в `tests/`.
7. Проверять изменения локально (curl + headless-браузер) перед пушем.
8. Обновлять DEVLOG.md и вычёркивать пункты TODO.md по ходу работы.
9. При изменении файлов в `public/` поднимать `VERSION` в `public/sw.js`,
   чтобы у пользователей очистился устаревший офлайн-кэш данных.

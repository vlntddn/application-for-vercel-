инфраструктура и юридика — в последнюю фазу.

- [x] Страница теории: прогресс чтения, галерея знаков главы,

      muted в тёмной теме 0.45→0.62, декоративные бары скрыты от AT
- [x] PWA: manifest + service worker, офлайн-режим, кнопка «DOWNLOAD FOR
      OFFLINE» в настройках, иконка на домашний экран
- [x] Очередь офлайн-ответов: localStorage-очередь с реплеем по порядку

## Принятые решения (не пересматривать без причины)
- Ноль runtime-зависимостей до Фазы 3; первая зависимость — драйвер
  SQLite, если встроенного node:sqlite не хватит
- Секреты только в .env; фронтенд не хранит ничего чувствительного
- Вся мутация данных — на сервере; фронт только сообщает события

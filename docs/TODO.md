**Критерии качества перевода (проверяются на КАЖДОЙ категории, до коммита):**
1. Дословная точность: перевод не меняет смысл — VERO/FALSO вопроса
   остаётся тем же; чисел (метры, км/ч, секунды, номера статей) нет
   переделанных — сверить с text_it поштучно.
2. Терминологическая консистентность: один итальянский термин = один
   перевод во всей категории (сравнить со словарём data/dictionary.json:
   sorpasso=обгон, segnale=знак, precedenza=преимущество и т.д.);
   несовпадения со словарём — исправлять в сторону словаря.
3. Грамматика: перевод читается как родной язык, а не калька; для ZH —
   иероглифы, не пиньинь; для RU — естественный порядок слов.
4. Полнота: все N вопросов категории имеют перевод в target-языке
   (проверить скриптом, не «на глаз»).
5. Валидация: `npm test` зелёный + smoke-эндпоинты 200.

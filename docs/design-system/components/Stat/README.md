# Stat

A card with a label, one large number and one line of context; the home screen shows three in a row.

**Provide:** label (uppercase, 13px), value (`display`-scale, 44px, tabular), sub line in `ink-muted`. Value colour says what kind of number it is: `accent-ink` for streaks, `ok` for mastery, `ink` for everything else.

**Do:** show a friendly zero ("Start today") in the sub line instead of a bare 0; stack to one column under 480px. **Don't:** use `accent` itself for the number (2.9:1 on `paper`), or add a third line.

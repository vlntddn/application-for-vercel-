# Tag

A short uppercase label for metadata or status, 12px minimum (the source's 10px tags are gone).

**Provide:** one to three words. Status tags (`ds-tag--ok`, `ds-tag--bad`) always carry an icon (check, cross) and the word, so meaning never rests on colour alone.

**Variants:** default (`surface`) for neutral metadata such as chapter numbers; `--accent` for content type (Lesson); `--warn` for New and Guide; `--ink` for counters; `--ok` and `--bad` for answer results.

**Do:** cap a card at two tags. **Don't:** make a tag tappable (use a Button), wrap the label, or set text on `accent` in anything but `on-accent`.

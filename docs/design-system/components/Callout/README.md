# Callout

A boxed message with an icon block, a short title and one or two sentences.

**Provide:** a title (uppercase label), text (`body`), an icon that matches the tone: guide (`warn` block, dark bulb), tip (`accent` block), success (`ok-soft` block with a check), alert (`bad-soft` block with a triangle). Tone lives in the icon block, not in a coloured left border.

**Notice strip:** `ds-notice` is the one-line variant for persistent info such as the privacy note. It is dismissible and never fixed to the bottom of the screen: the source's fixed footer collided with the tab bar on phones.

**Do:** keep to one callout per screen section; put an action on the right only when it is the natural next step. **Don't:** stack callouts, or use `bad` for anything that is not an error or a countdown.

# План: учебная часть Passo (Learning)

Составлен 2026-09-29 архитектором по запросу владельца. Задачи для исполнителя —
в `docs/OPENHANDS-ROADMAP.md`, **Спринт L** (там они атомарные, с проверками).
Этот файл — «зачем и как устроено»; исполнитель читает его перед задачами L.

## Для кого и в чём задача

Passo — для экспатов: человек сдаёт экзамен на **итальянском, которого не знает**.
Экзамен: 30 утверждений, 20 минут, ≤ 3 ошибки, ответ VERO/FALSO. Проваливаются
чаще не из-за правил, а из-за **формулировок**: одно слово («solo», «purché»,
«salvo») переворачивает смысл. Продукт должен учить трём вещам:

1. **Читать экзаменационный итальянский** — слова-сигналы, конструкции, числа.
2. **Знать правила** — по главам, в понятном порядке, с повторением.
3. **Понимать свою готовность** — где ошибаюсь и почему, сколько осталось.

## Рынок (сентябрь 2026)

| Кто | Сильная сторона | Чего нет |
|---|---|---|
| Quiz Patente Tradotto / Multilingua / per Stranieri | перевод на 100+ языков, аудио, пояснения, «важные слова подсвечены» | обучение чтению итальянского, путь обучения, повторение по науке |
| Italian Patente Prep (EN) | гид из 10 глав на английском | статистика формулировок, персональная диагностика |
| Zutobi (не Италия) | интервальное повторение, короткие главы, readiness, геймификация | итальянского рынка и языкового слоя |

**Ниша Passo:** единственный, кто учит *языку экзамена* на реальной статистике банка
и объясняет, *почему* ты ошибаешься (формулировка / знак / число / правило), плюс
путь обучения с повторением. Перевод — слой по запросу (решение Фазы 1: сначала
итальянский).

## Главный принцип: подсказки только на фактах

Сила ИИ здесь — **анализ банка из 7139 вопросов**, а не сочинение советов. Каждая
подсказка в продукте обязана быть одного из трёх видов:

1. **Посчитана по банку** скриптом (воспроизводимо, тест сверяет с банком);
2. **Взята из уже вычитанных уроков** (`lessons.json`);
3. **Сгенерирована моделью, но прошла автоматические гейты** и помечена как черновик
   (только Фаза L9, только после решения владельца).

Проверка идеи на данных (2026-09-29, весь банк, доля FALSO при базе 50%):

| слово | вопросов | FALSO | вывод для ученика |
|---|---|---|---|
| solo | 246 | **75%** | сильный сигнал «ищи исключение» |
| purché («при условии») | 61 | 74% | условие часто выдумано |
| soltanto | 31 | 71% | как solo |
| è obbligatorio | 78 | 71% | «обязательно» часто преувеличено |
| sempre | 80 | **66%** | ⚠ каждый 3-й ВЕРНЫЙ — «sempre = FALSO» провалит треть |
| tutti | 108 | 64% | обобщение — насторожиться |
| deve / può | 702 / 621 | 40% / 39% | модальные — скорее ВЕРНО |
| salvo («кроме») | 50 | **28%** | исключение уже названо → чаще ВЕРНО |

Это и есть «нетривиальные подсказки»: не «всегда = ложь», а **честная вероятность +
реальный контрпример из банка**. Никто на рынке так не делает.

## Архитектура

- **Данные-инсайты** генерируются скриптом `scripts/build-insights.mjs` из банка в
  `data/insights/*.json` (коммитятся; тест проверяет, что файл совпадает с тем, что
  скрипт посчитает сейчас — нельзя «подправить руками»).
- **Логика обучения** — чистые функции в `public/js/domain/learning.js` (работают и в
  браузере, и в тестах; глобальный `state` не читают). Это задача T2 техдолга —
  становится фундаментом L0.
- **Прогресс**: новые поля ответа (`streak` — подряд верных, `due` — дата повтора)
  только через `domain/progress.js` с миграцией и валидацией (правило проекта).
- **UI** — компоненты дизайн-системы (Callout, Card, Tag, Question, Feedback).
- Режим экзамена **без подсказок** (честная тренировка); подсказки — в практике,
  теории и разборе ошибок.

## Фазы и порядок

```
L0 domain/learning.js (=T2) ─┬─ L1 инсайты слов ── L2 подсветка в вопросе ── L3 причины ошибок
                             │                                         ✓ Checkpoint A
                             ├─ L4 шпаргалка чисел
                             ├─ L5 путь обучения ── L6 интервальное повторение ── L7 готовность
                             │                                         ✓ Checkpoint B
                             └─ L8 слово по тапу (после Спринта 4 словаря)
L9 пояснения к вопросам от модели — 🔒 только по решению владельца  ✓ Checkpoint C
```

Самое ценное и наименее рискованное — первым (L1–L3: язык экзамена). Рискованное
(изменение формата прогресса L6, генерация контента L9) — после фундамента и с
чекпоинтами.

## Чекпоинты (владелец смотрит превью-ссылку self-improve)

- **A (после L3):** на экране «L'italiano dell'esame» — реальные проценты и
  контрпримеры; в практике слова-сигналы подчёркнуты; в «Ошибках» — «чаще всего вы
  ошибаетесь на …». Решение: выкладывать в main?
- **B (после L7):** путь обучения ведёт новичка по главам; повторение приходит по
  расписанию; на главной — шанс сдать с объяснением. Решение: выкладка.
- **C (перед L9):** решение владельца о генерации пояснений.

## Риски

| Риск | Влияние | Митигация |
|---|---|---|
| Подсказка-эвристика учит «угадывать», а не понимать | Высокое | Всегда показывать долю ВЕРНЫХ исключений и контрпример; в экзамене подсказок нет |
| Модель-исполнитель «улучшит» проценты или примеры руками | Высокое | Инсайты только из скрипта + тест «файл = скрипт(банк)» |
| Изменение формата ответов ломает старый прогресс | Высокое | Миграция в domain + тест на снапшоте старой версии; поле опционально |
| Оценка готовности вводит в заблуждение | Среднее | Показывать диапазон и «на основе N ответов», не показывать до 150 ответов |
| Пояснения модели неверны (как было с переводами Gemini) | Высокое | L9 заблокирован; при запуске — гейты + пометка «черновик» + вычитка владельцем |
| Задача не влезает в 20–30 мин запуска | Среднее | Каждая L-задача ≤ 5 файлов, крупные разбиты на a/b |

   умолчанию первые 100 вопросов, потом — выключаемо в настройках.
